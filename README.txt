IWBAM 2.0 - prototipo inicial
Abre index.html en un navegador moderno. Guarda movimientos en localStorage del navegador.
Incluye cuentas, movimientos, transferencias, edición, eliminación, modo sencillo/avanzado, monedas y exportación/importación JSON.
No es aún una versión de producción ni una PWA instalable/offline garantizada.
Para publicar en GitHub Pages, coloca index.html en la raíz del repositorio y activa Pages en Settings > Pages.
Importante: guarda copias de respaldo; borrar datos del navegador puede borrar movimientos.
